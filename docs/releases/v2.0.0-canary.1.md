The first tagged release of v2 — a loopback-only, OpenAI-compatible inference
server for running coding agents against a local model on Windows and AMD ROCm.
This is a **canary pre-release**: production promotion stays blocked by the open
gates listed below.

## What's in it

- `cia-edge` — data and control plane: OpenAI Chat Completions and Responses,
  Anthropic Messages, route contracts, capability gating, a bounded queue and
  bounded decompression, and no cloud fallback.
- `cia-supervisor` and `cia-credential` — Job Object containment with restart
  backoff, and the Windows Credential Manager helper.
- `cia-tray` (IA Local) and `cia-monitor` — the single startup entry and the
  browser monitor.
- `cia-mcp`, `cia-mcp-inference` and `cia-mcp-admin` — read-only operations,
  stateless delegation, and opt-in administration over MCP.
- `cia-manifest` — JSON Schema validation for the model manifest.
- `models.schema.json`, `llama-swap.template.yaml`, `edge.sample.yaml`, a
  CycloneDX SBOM, `SHA256SUMS` and `release-metadata.json`.

## Measured on the canary

| Measure | Result |
|---|---|
| Edge overhead | p95 of 18.2 ms over 30 short, warm request pairs, against a 50 ms gate |
| Long-context recall | Qwen3.6 35B-A3B 120/120 up to 240k tokens; Gemma 4 12B 59/60 |
| Real agent session | Codex on the Agent profile fixed a failing Go test end to end in 114 s |

## Known limitations

- All four models are `candidate`; nothing is promoted to production.
- The Huge profile's physical revalidation is pending: its admission gate needs
  18.2 GiB of free RAM.
- The 72-hour soak was waived and is recorded as `waived`, not as evidence of
  long-run stability.
- Windows/amd64 only. Serving needs an AMD GPU with a ROCm build of
  `llama-server`; no model weights or runtime executables are distributed.
